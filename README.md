# 🌍 World Population Web Scraping & Data Analysis

## 📌 Project Overview

This project demonstrates how to collect world population data using web scraping techniques and perform exploratory data analysis (EDA) using Python.

The project includes:
- Web scraping
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Insights from the dataset

---

## 🛠️ Technologies Used

- Python
- BeautifulSoup
- Requests
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

---

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Divya-Sree-12345/web-scraping-data-analysis.git
```

2. Install dependencies

```bash
pip install pandas numpy matplotlib beautifulsoup4 requests
```

3. Open

```
Web_Scrapping_Project.ipynb
```

and run all cells.
